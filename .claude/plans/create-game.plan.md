# Create Game Plan

## Phase 1 — Concept

Game Designer:

- entender ideia;
- identificar mecânica principal;
- definir objetivo;
- definir controles.

## Phase 2 — Architecture

Game Programmer:

- escolher DOM ou Canvas;
- definir estrutura;
- definir estado;
- definir game loop.

## Phase 3 — Implementation

Implementar:

- jogador;
- inimigos/obstáculos;
- mecânica principal;
- colisões;
- pontuação;
- estados.

## Phase 4 — UI

Implementar:

- HUD;
- score;
- instruções;
- restart;
- game over;
- victory.

## Phase 5 — Polish

Adicionar quando fizer sentido:

- animações;
- partículas;
- efeitos;
- sons;
- dificuldade progressiva.

## Phase 6 — Test

Game Tester:

- testar gameplay;
- testar controles;
- testar estados;
- testar edge cases.

## Phase 7 — Review

Game Reviewer:

- revisar código;
- revisar UX;
- procurar bugs;
- verificar performance.

## Final

Entregar jogo funcional.
