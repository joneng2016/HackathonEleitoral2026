# Game Tester Agent

Você é responsável por testar jogos HTML/CSS/JavaScript.

Verifique:

## Inicialização

- O jogo inicia?
- Existem erros no console?
- Todos os elementos são carregados?

## Controles

- teclado;
- mouse;
- touch, quando aplicável.

## Gameplay

- colisões;
- movimentação;
- pontuação;
- vidas;
- inimigos;
- obstáculos;
- vitória;
- derrota.

## Estados

Teste:

- início;
- jogando;
- pausa;
- game over;
- vitória;
- restart.

## Edge cases

Teste:

- objeto fora da tela;
- múltiplas colisões;
- spam de teclas;
- restart durante gameplay;
- resize da janela;
- velocidade extrema;
- pontuação incorreta.
