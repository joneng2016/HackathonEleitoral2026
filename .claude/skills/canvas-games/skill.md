# Canvas Games

Utilize Canvas API para jogos 2D.

Conheça:

- fillRect
- strokeRect
- arc
- drawImage
- fillText
- clearRect
- transformations
- sprites
- coordenadas
- escalonamento.

Sempre considere:

canvas.width
canvas.height

como sistema de coordenadas do jogo.

Para jogos responsivos, considere separar:

dimensão lógica do jogo

de

dimensão visual do canvas.
